# Histórico de decisões arquiteturais

Este diretório preserva decisões de versões e fontes anteriores para provenance. O histórico ajuda a entender origem, supersession e migração; **não governa automaticamente a árvore canônica corrente**.

| Artefato | Papel histórico |
|---|---|
| `0003-single-canonical-source-and-guide-absorption.md` | Registro da absorção do guia em uma fonte canônica modular. |
| `0006-framework-release-1-0-adoption.md` | Adoção histórica da release 1.0. |
| `0011-framework-release-1.1-adoption.md` | Adoção aceita da release 1.1.0; preservada para evitar colisão com a ADR-0015 corrente. |

Mudanças correntes devem ser registradas em [`docs/architecture/decisions/`](../../../docs/architecture/README.md) e no [decision log](../../../docs/architecture/decision-log.md). A preservação deste diretório não transforma qualquer decisão histórica em requirement atual.
