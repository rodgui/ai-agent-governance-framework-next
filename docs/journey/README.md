# Guias de implantação

- [Implementation playbook](../framework/08-implementation-and-adoption.md) — método canônico com G0–G7, entregáveis e critérios de saída.
- [Roadmap de implantação — 90 dias](../framework/08-implementation-and-adoption.md) — referência acelerada para quem precisa de uma sequência inicial; não é SLA.
- [Programa de implantação — 24 semanas](../framework/08-implementation-and-adoption.md) — pattern detalhado e adaptável, com mapeamento fase↔gate; não é calendário normativo.
- [Plano opcional de piloto e critérios de expansão](../framework/08-implementation-and-adoption.md) — uma rota possível para validar a governança; cohort, phased rollout ou evidência equivalente também são válidos.
- [Capability map — atual versus alvo](../framework/08-implementation-and-adoption.md) — o que a organização precisa saber fazer, antes de escolher ferramenta.
- [Maturity model](../../toolkit/maturity/maturity-model.md) — dez dimensões, níveis 0–4, confidence, coverage e target state.

Os guias operacionalizam a [policy modular](../framework/00-document-control.md). Alterações normativas exigem revisão, authority, changelog e release; roadmap, prazo, piloto ou exemplo não criam adoção automática. Organizações podem adaptar a sequência desde que preservem decision rights, gates e evidências.
